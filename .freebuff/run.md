# Run Doc — Portfolio Dev Server

## Reproduce uncommitted artifacts
No special build step needed — Vite serves from source with HMR.

## Run the dev server
```bash
cd /d/portfolio/d1
npm run dev
```
Default port: 5173.

## Notes
- Node modules are already installed.
- No `.env` or secrets required.
- The `agentation` dev tool connects to `localhost:4747` (optional, not needed for the site to work).
